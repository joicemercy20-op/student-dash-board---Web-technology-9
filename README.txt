EXPERIMENT 8 (AS LABELLED IN THE UPLOADED PDF): REACTJS STUDENT DASHBOARD

This project follows the uploaded lab PDF's ReactJS Student Dashboard description:
Dashboard, Courses, Assignments, Profile, navigation, statistics, course progress,
assignment status, and light/dark theme switching.

REQUIREMENTS
- Install Node.js (LTS) from https://nodejs.org/
- VS Code (recommended)

HOW TO RUN
1. Extract this ZIP file.
2. Open the extracted Experiment_React_Student_Dashboard folder in VS Code.
3. Open Terminal > New Terminal.
4. Run:
      npm install
5. Then run:
      npm run dev
6. Open the local URL shown in the terminal (usually http://localhost:5173).

FEATURES TO TEST
- Click Dashboard, Courses, Assignments, and Profile in the left menu.
- Click Dark Mode / Light Mode in the top-right corner.
- Resize the browser to check the responsive layout.

NOTE
The PDF title says "Developing ServerSide Application using Node JS", but its
actual description, procedure, and source code are for a ReactJS Student Dashboard.
This ZIP follows the actual ReactJS program shown in the PDF.
